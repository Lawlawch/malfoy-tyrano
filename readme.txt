Main Features

-- Runs on HTML and JavaScript
With TyranoScript, you can publish your game across a wide range of platforms.
Experience game development in the multi-platform era.
Once your game is complete, it can be played on Windows, Mac, iPhone, Android, and even as a browser game.

-- Seamless Integration with JavaScript
TyranoScript allows you to freely write and extend your code with JavaScript.

-- Comes with Advanced Development Tools
Using the dedicated development tool "TyranoStudio" enables efficient development.
It supports effective debugging, translation assistance, and easy creation of executable files.

-- Free & Commercially Usable
It is available free of charge, and commercial use is permitted.
The source code is open, so you are free to modify it as long as your goal is to create a work.
