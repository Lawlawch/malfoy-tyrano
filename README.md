## v8 修改
- **劇本更新後，舊存檔可以讀取**（不再封鎖）。做法是「場景錨點」：
  - 劇本場景開頭寫 `*a_xxx` 再接 `[anchor id="a_xxx"]`（標籤名與 id 要一致）。錨點會把當下的隱藏數值存進存檔。
  - 存檔分「格式」（`VN.SAVE_FORMAT`，只有存檔資料結構改了才升，不同格式的存檔無法讀取）與「劇本版本」（`VN.SAVE_VERSION`，劇本有改動就升）。
  - 劇本版本不同的存檔：讀取時跳出「劇本已更新，將從該段落開頭繼續」，還原錨點時的數值，從錨點重播。找不到錨點（被刪或改名）就退回章節開頭，用存檔裡記的章節起點數值。「繼續」（自動存檔）走同一套。文字紀錄會清空。
  - 章節檔開頭、角色宣告之後要放「讀檔閘門」（見 `ch1_01.ks`）；新章節照抄。
  - 錨點規則：放在場景開頭，錨點之後要自己重建背景／音樂／角色；id 用過就不要改名、不要重複。改完劇本可執行 `python3 tools/check_anchors.py` 檢查。
- 通關一章時，不論下一章是否已上線，都會記下「通關時的數值」並解鎖下一章；之後章節上線，儲思盆會直接出現
- 儲思盆選到「要沿用舊時間線快照」的章節（超過目前時間線走到的章節）時，確認框加一句「此章將沿用先前的進度。」；有自動存檔時兩句並列
- 注意：v7 以前的存檔沒有錨點資料，無法讀取，請用新遊戲

## 劇本寫法
章節檔開頭：`[chapter_begin id="ch1_01" title="第一年級・第一章　標題"]`
章節檔結尾：`[end_chapter id="ch1_01"]` 後接 `@jump storage="title.ks"`（主線會顯示章末頁並停住，重玩則直接回儲思盆）
選項：`[choice_start]` → 數個 `[opt ...]` → `[choice_end]` → `[s]`
解鎖：`[unlock_cg id="cg_mirror"]`、`[unlock_end id="y1_A"]`

## 請你測試
1. **首頁**：按鈕位置、hover 效果；轉向。
2. **新遊戲 → 玩到選項 → 讀檔 → 選擇回溯**：是否出現剛才的選擇點，載入後是否回到選項前。
3. **存檔**：存到手動格、再存同一格是否出現覆蓋確認；到讀檔讀回。
4. **繼續**：關掉分頁重開，首頁是否有「繼續」。
5. **章末**：打完第一章是否出現書頁畫面；「下一章」是否反灰；「儲思盆」「回首頁」是否正常。
6. **儲思盆**：打完後第一章是否可重玩；重玩結束是否回到儲思盆；其他章節是否都是鎖定空格。
7. **圖鑑**：在圖鑑下方點「全部解鎖」測試翻頁與放大。
8. **設定**：文字速度、自動速度、字體大小（遊戲中即時生效）、略過已讀開關、音量滑桿。
9. 遊戲中按 Enter／空白鍵時，開著的面板底下的劇情不應前進。
